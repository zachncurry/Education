### Cornell University
**Professional Development - Project Management**</br>
Completed 2019</br>
[View Certfication](https://github.com/zachncurry/Education/blob/eca6e2ea292adbdbc17cde0dc9da899ef2f61166/Zach.Curry.Cornell.ProjectManagementCertificate.pdf)</br>

The program spans five core courses plus an optional PMP study group, covering the entire project management life cycle:
1. **Project Structuring & Scheduling:** Mastering Work Breakdown Structures (WBS), network diagrams, critical path method (CPM), float calculations, and PERT estimations to schedule complex dependencies.
2. **Resource Optimization & Constraint Planning:** Structuring resource allocation models, handling capacity bottlenecks, and executing project compression strategies (crashing/fast-tracking) to bring delayed projects back on track.
3. **Earned Value Management (EVM):** Applying quantitative financial metrics—such as Cost Variance (CV), Schedule Variance (SV), CPI, and SPI—to objectively audit project performance and forecast final costs.
4. **Risk Identification & Mitigation:** Quantifying project risks, calculating contingency buffers, and developing proactive response strategies rather than reacting to crises reactively.
5. **Agile & Hybrid Frameworks:** Adapting classical waterfall project controls to iterative, Agile environments when requirements are fluid or highly variable.
